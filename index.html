동아리 소개

강원대학교 게임개발 중앙동아리 포테니티
POTATO + UNITY

포테니티는 강원대학교 게임 개발 중앙 동아리로,
게임 기획, 프로그래밍, 그래픽, 사운드 등 다양한 분야의 학생들이 모여
창의적이고 혁신적인 게임을 함께 만드는 곳입니다.

Unity를 활용한 프로젝트와
정기 스터디, 팀 프로젝트, 게임 개발 강의 등 다양한 활동을 통해 실력을 키우고 있습니다.
게임 개발에 열정이 있다면 누구나 환영합니다!

정기 활동

  • ⏰ 정기 활동 시간: 평일 오후 6시 ~ 8시 30분 (모든 활동은 자율 참여)
  • 🤝 팀 프로젝트 : 주에 2회(팀원들끼리 상의 후 결정)
  • 🍕 푸드데이 일정 : 2주에 한 번(부원들끼리 상의 후 결정)

❓ 자주 묻는 질문

Unity 설치가 안 돼요

  • 구글에 '구라제거기' 검색 후 실행 - 은행 보안 프로그램이 문제인 경우가 많습니다
  • 알약, V3 같은 국산 보안 프로그램도 확인해보세요
  • 그래도 안 되면 Unity 아카이브에서 직접 에디터 설치파일을 받아 설치하세요

Unity 프로젝트 경로 설정은 어떻게 하나요?

⚠️ 중요: 절대 한글 경로가 있는 곳에 프로젝트를 생성하지 마세요!

C드라이브나 D드라이브에 "Unity Workspace" 같은 영문 폴더를 만들고 그 안에 프로젝트를 생성하세요.

Unity가 뭔가 이상해요

Assets → Reimport All 메뉴를 클릭하세요. 프로젝트를 완전히 새로고침하는 메뉴입니다.

기획, 아트도 스터디해야 하나요?

책에 있는 기초 내용까지는 모두 진행하기를 권장합니다. 협업할 때 최소한의 지식이 있는 것이 중요해요.

이후 관심 분야(캐릭터 아트, 배경 아트, 기획 등)를 정해서 회장에게 알려주세요!

모든 활동에 참여해야 하나요?

아니요! 모든 활동은 자율 참여입니다. 편한 시간에 오시고 가실 수 있어요.

Rider가 Unity에서 안 열려요

Preferences → External Tools → External Script Editor를 Rider로 변경하세요.

코드 자동 정리: Rider 설정 → Tools → Actions on Save → Reformat and clean up code 활성화
