Club Introduction

Kangwon National University Central Game Development Club Potanity
POTATO + UNITY

Potanity is the central game development club at Kangwon National University,
where students from various fields such as game planning, programming, graphics, and sound gather
to create creative and innovative games together.

We hone our skills mainly through team projects using Unity.
Anyone passionate about game development is welcome!

If you want to check the other tabs, click "Development Division" to see them all.

Regular Activities

  • ⏰ Regular Activity Hours: Weekdays 6 PM - 8:30 PM (All activities are voluntary)
  • 🤝 Team Projects: Twice a week (decided after discussion among team members)
  • 🍕 Food Day Schedule: Once every two weeks (decided after discussion among members)

Team Projects

  • 🧩 Provided by the club: The club implements the common elements of a specific game genre in advance and provides them.
  • 🧭 Project direction: Based on what is provided, teams discuss and decide additional elements together, then reflect them in the game.
  • ✅ Completed genres: Clicker game, platformer game
  • 📅 Start timing: Beginning of the semester, after the vacation starts
  • 🔀 Group division: Completion-focused group / Rule-focused group
  • 🏁 Completion-focused group goal: Completion itself is the goal. Focused on finishing, so work is relatively relaxed.
  • 📐 Rule-focused group goal: Following development rules such as SOLID principles so that even large-scale games are built with fewer problems.
  • ⚖️ Difference between the two groups:
    • Programming: Additionally apply SOLID principles and specific syntax
    • Design: Organize the numeric values used in the game in a spreadsheet
    • Art: Unify animation specifications

Roles in the Club

  • 📝 Design: Game concept and story development, game system and balance design, etc.
  • 💻 Programming: Implementing game logic and systems, bug fixing and feature optimization, etc.
  • 🎨 Art: Character and background design, UI / UX design and effects work, etc.
  • 🎵 Sound: Composing and selecting background music, sound effect design, etc.
  • 🔍 QA: Gameplay testing, finding bugs, etc.

❓ Frequently Asked Questions

Unity won't install

  • Search for "Gura Remover" on Google and run it - banking security programs are often the problem
  • Check Korean antivirus programs like ALYac and V3 as well
  • If it still doesn't work, download Unity editor installer directly from Unity archive

How to set Unity project path?

⚠️ Important: Never create projects in paths with Korean characters!

Create an English folder like "Unity Workspace" on your C or D drive and put your projects inside it.

Unity is acting weird

Click Assets → Reimport All menu. This completely refreshes the project.

Do I have to participate in everything?

No! All activities are voluntary. Come and go whenever it's convenient for you.

Rider won't open from Unity

Go to Preferences → External Tools → External Script Editor and change it to Rider.

Auto code formatting: Rider Settings → Tools → Actions on Save → Enable "Reformat and clean up code"
